One command for Linux (x86_64, arm64) and Apple Silicon Macs. No sudo, and nothing stays behind unless you keep it.

Skip the menu and start the quick suite: curl -fsSL {{ run_url }} | sh -s -- run quick

What the script does

  • Detects your OS and CPU with uname and picks the matching release binary. Intel Macs and Windows are not supported yet.
  • Downloads the binary and its .sha256 file from the latest GitHub release into a temporary directory, and aborts if the checksum does not match.
  • Starts the menu in your terminal. Every action returns to it, and Ctrl+C cancels a running benchmark.
  • Deletes the binary when you quit. Before that, benchpress offers to remove the toolchains and sources it downloaded.
  • Runs everything inside a function called on its last line, so a partially downloaded script never runs.

The command fetches the script straight from the GitHub repository. Read it first if you like.

Where data goes

Toolchains, sources and crates
Linux ~/.cache/benchpress
macOS ~/Library/Caches/benchpress
Build directories, removed after each run
Linux /var/tmp/benchpress-<uid>
macOS $TMPDIR/benchpress
Results and unpublish tokens
Linux ~/.local/share/benchpress
macOS ~/Library/Application Support/benchpress

Manage local data in the menu shows the size of each and removes them. You can also delete the folders yourself. Your own ~/.rustup and ~/.cargo are never touched.

Install it instead

curl -fsSL {{ run_url }} | sh -s -- install puts the binary in ~/.local/bin (or $BENCHPRESS_INSTALL_DIR). Then:

  • benchpress opens the menu.
  • benchpress run quick runs the smallest suite, about a minute or two.
  • benchpress doctor checks your setup without running anything.
  • benchpress clean removes cached toolchains, sources and build directories; --all removes results too.
