Install

One command for Linux (x86_64, arm64) and Apple Silicon Macs. No sudo.

{{ install_box("install-cmd") }}

To install and start the default suite right away: curl -fsSL {{ public_url }}/install.sh | sh -s -- run

What the script does

  • Detects your OS and CPU with uname and picks the matching release binary. Intel Macs and Windows are not supported yet.
  • Downloads the binary and its .sha256 file from the latest GitHub release and aborts if the checksum does not match.
  • Installs to ~/.local/bin (or $BENCHPRESS_INSTALL_DIR) and tells you the line to add if that directory is not on your PATH.
  • Runs everything inside a function called on its last line, so a partially downloaded script never runs.

Then

  • benchpress picks a suite interactively and shows the time and disk it needs.
  • benchpress run quick runs the smallest suite, about a minute or two.
  • benchpress doctor checks your setup without running anything.
  • benchpress clean removes cached toolchains, sources and build directories.
